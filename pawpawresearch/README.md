# Pawpaw Research Alliance

This is a multi-page website dedicated to introducing the North American pawpaw (Asimina triloba), the largest edible fruit native to the United States.

The main purpose of this website is to share basic knowledge about the pawpaw tree, including its biology, habitat, cultivation, and research value. All information is presented in a clear and accessible way to help more people learn about this unique native fruit.

Please note that the Pawpaw Research Alliance is a completely fictitious organization. It was created only for educational and portfolio demonstration purposes. The biological content on the website is based on real scientific knowledge, but the organization itself does not exist.
